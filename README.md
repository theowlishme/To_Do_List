# To_Do_List

This is a simple console-based To Do List program written in C.

The program allows the user to:
- Add tasks
- View all added tasks

## Features
- Menu-driven program
- Tasks can contain spaces because i used fgets
- Uses arrays to store tasks

## Concepts Used
- Arrays
- while loop
- if-else statements
- fgets for input
- Basic input/output
